## 📚 О проекте

**Crypto Project** — это веб-приложение для безопасного локального шифрования файлов в браузере. Приложение быстрое, безопасное и использует современные криптографические алгоритмы с потоковым шифрованием/дешифрованием AEAD по частям.

Проект реализует эффективное по памяти шифрование больших файлов в браузере с использованием потоков и libsodium.

## ✨ Основные возможности

### Безопасность

- **XChaCha20-Poly1305** - для симметричного шифрования
- **Argon2id** - для выведения ключей на основе пароля
- **X25519** - для обмена ключами

Все криптографические алгоритмы реализованы с использованием библиотеки libsodium.

### Функциональность

- 🔐 Безопасное шифрование/дешифрование нескольких файлов с использованием паролей или ключей
- 🔑 Генерация безопасных случайных паролей
- 🔄 Генерация асимметричных пар ключей
- 🔒 Аутентифицированный обмен ключами
- 📊 Оценка надежности пароля

### Приватность

- Приложение работает локально в браузере
- Данные никогда не собираются и не отправляются на сервер

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
```bash
git clone https://github.com/frametamer/crypto_project.git
cd crypto_project
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект в режиме разработки:
```bash
npm run dev
```

4. Откройте браузер и перейдите по адресу `http://localhost:3000`

## 🛠 Технологический стек

- **Next.js** - React фреймворк для веб-приложений
- **Material-UI** - UI компоненты и дизайн-система
- **libsodium.js** - криптографическая библиотека
- **Cypress** - end-to-end тестирование

## 📦 Развертывание

### Локальное развертывание

Проект можно легко развернуть самостоятельно. Для продакшена:

```bash
npm run build
npm start
```

## 📚 О проекте

**Crypto Project** — это студенческий проект, представляющий собой веб-приложение для безопасного шифрования файлов в браузере. Проект демонстрирует использование современных криптографических алгоритмов для локального шифрования файлов без отправки данных на сервер.

## 🎯 Цель проекта

Изучение и практическое применение криптографических алгоритмов в веб-разработке, создание безопасного инструмента для шифрования файлов с использованием современных технологий.

## ✨ Основные возможности

### Безопасность

- **XChaCha20-Poly1305** - для симметричного шифрования
- **Argon2id** - для выведения ключей на основе пароля
- **X25519** - для обмена ключами

Все криптографические алгоритмы реализованы с использованием библиотеки libsodium.

### Функциональность

- 🔐 Безопасное шифрование/дешифрование нескольких файлов с использованием паролей или ключей
- 🔑 Генерация безопасных случайных паролей
- 🔄 Генерация асимметричных пар ключей
- 🔒 Аутентифицированный обмен ключами
- 📊 Оценка надежности пароля

### Приватность

- Приложение работает локально в браузере
- Данные никогда не собираются и не отправляются на сервер

## 🚀 Использование

1. Клонируйте репозиторий:
```bash
git clone https://github.com/frametamer/crypto_project.git
cd crypto_project
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект:
```bash
npm run dev
```

4. Откройте браузер и перейдите по адресу `http://localhost:3000`

## 🛠 Технологии

- **Next.js** - React фреймворк для веб-приложений
- **Material-UI** - UI компоненты
- **libsodium.js** - криптографическая библиотека
- **Cypress** - тестирование

## 📦 Установка для продакшена

Проект можно легко развернуть самостоятельно. Следуйте инструкциям в разделе [Installation](pages/about.js).

## 🌐 Совместимость с браузерами

Проект поддерживает последние две версии всех основных браузеров:

- **Chrome** на Windows, macOS, Linux, Android
- **Firefox** на Windows, macOS, Linux
- **Safari** на iOS и macOS
- **Edge** на Windows

> ⚠️ Safari и мобильные браузеры ограничены файлами размером до 1GB из-за отсутствия поддержки server-worker fetch API.
